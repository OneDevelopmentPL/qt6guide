# Qt6 Basics

A concise tutorial on creating a basic Qt6 application from scratch.

## Prerequisites

* Install Qt using the [Qt Installation Guide](https://onedevelopmentpl.github.io/qt-installation/).
* (press the green button on the site)

## Project Structure

Create a folder containing two files:
* `CMakeLists.txt`
* `main.cpp`

## Configuration & Code

Add the required configuration to `CMakeLists.txt` and the basic window implementation to `main.cpp` to set up your Qt6 Widgets application. (code available in the project files)

## Build and Run

1. Open the project in VS Code.
2. Select your compiler kit via CMake.
3. Configure, build, and run the executable.
